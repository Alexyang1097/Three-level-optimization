# 训练损失、Recursive risk 与 RTF 联合分析

日期：2026-10-15

本文分析磁盘“杨奕麟-嘉祥”中 `runs/main_budget_4000` 的结果，对比 Uniform Sum、Unconstrained Stages、Primal–Dual Stages 与 EMO。所有数值取 `selected` 模型，跨优化种子 11、22、33 汇总；每个分布包含 256 个测试任务，示例数量为 `n ∈ {1,2,4,8,16,32}`。本文使用“RTF”表示 teacher-forced test risk，即数学记号中的 `R^TF`。

## 1. 核心结论

1. **不存在在全部步骤、分布和示例数量上都占优的方法。** Primal–Dual 的 OOD 前两步递归误差均值在六个 `n` 下均最低，但较多示例时，OOD 最终答案以 Uniform 最好。ID 最终一步则在多个 `n` 下以 Primal–Dual 最好。
2. **RTF 与 recursive 的排名可以不同。** Primal–Dual 在 `n=32` 的 ID 第三步 RTF 高于 Uniform，recursive 却更低；在 OOD 第二步也出现类似的排名反转。只看 RTF 或只看 recursive 都会遗漏重要差异。
3. **较小的 recursive–RTF 差值不等于预测能力更强。** Primal–Dual 的 OOD 第三步差值较小，但 RTF 较高，最终 recursive 仍落后。EMO 的第三步差值接近零甚至为负，但两种模式都很差，是更明显的反例。
4. **当前 EMO 的第三步落后首先应结合训练阶段解释。** 三个种子均在 level 2 耗尽 4000 次 backward，尚未进入包含 `f3` 的最终层优化。它的第三步 RTF 已经很高，因此不能主要用递归误差传播解释其落后。
5. **示例增加带来的单步收益，不一定完整转化为递归收益。** 以 Uniform 的 ID 第三步为例，`n=1→32` 时 RTF 降低 2.621，recursive 只降低 0.743，同时两者差值增加 1.878。
6. **当前实验没有充分展示显式约束对于保护前层的必要性。** Uniform 的 `f3` 本身包含前两步损失，并且其三个种子从第 1500 次更新起，在全部已记录的评估点上均满足公共训练约束。这支持“当前设置下约束的额外必要性有限”，但不能直接证明各步梯度高度协同，也不能否定分阶段方案对泛化的条件性收益。

这些是当前配置下的描述性结果。三个优化种子共享固定数据池，均值排名不能自动解释为统计显著优势，也不能代表跨数据集或全部 OOD 分布的结论。

## 2. 指标定义与解读边界

### 2.1 两种推断模式

- **Recursive risk，`Rrec_j(n)`：**预测第 `j` 步时，query 的前序中间答案由模型自己生成。
- **Teacher-forced risk，`RTF_j(n)`：**预测第 `j` 步时，query 的前序中间答案替换为真实值；demonstrations、query 和当前预测目标保持配对。
- **前缀替换差值，`Delta_j(n) = Rrec_j(n) - RTF_j(n)`：**描述两种 query 前缀下的风险变化。

两种风险都是对测试任务平均的平方欧氏误差。先对输出维度求平方和，再对任务取平均；没有除以训练归一化系数 `A_j`，也没有除以输出维数。Step 1、2 为四维输出，Step 3 为一维输出。因此，应在相同步骤、分布和 `n` 下比较方法，不宜通过不同步骤的原始数值高度判断哪个步骤更难。

RTF 也是测试误差，不能与训练集上的归一化损失 `e_j` 混为一谈。本文的逐 `n` RTF 来自评估 JSON 中的 `recursive_id[n].tfj` 和 `recursive_ood[n].tfj`，不是仅在固定最大 prompt 长度上报告的归一化 `teacher_forced_id` 字段。

### 2.2 差值是配对诊断，不是独立的误差来源

恒等式

`Rrec = RTF + Delta`

可用于描述风险差异，但它不是已经识别出的因果分解。RTF 仍受模型参数、demonstrations、query 难度和评估分布影响；不同方法的前序预测误差大小、方向及相互关系也不同。

即使 `Delta` 更小，也可能只是 RTF 变大，或者不同误差出现抵消。对单个任务，记递归预测为 `a`、teacher-forced 预测为 `b`、目标为 `z`，则

`||a-z||² - ||b-z||² = ||a-b||² + 2<a-b, b-z>`。

交叉项可以为负，所以 `Delta` 不保证非负。报告中宜称其为“递归与 teacher-forced 风险差值”，不能直接称为非负的“累计传播误差”或“鲁棒性得分”。

Step 1 没有前序 query 预测，故 `Rrec_1 = RTF_1`；保存结果中的极小差值仅为数值计算差异。

## 3. n=32 的主要证据

本节数值均为三个优化种子的均值，保留三位小数。四舍五入后可能出现 0.001 的加总差异。

### 3.1 最终答案：第三步

| 分布 | 方法 | RTF₃ | Delta₃ | Rrec₃ |
|---|---|---:|---:|---:|
| ID | Uniform | 3.084 | 3.567 | 6.651 |
| ID | Staged | 3.196 | 3.120 | 6.316 |
| ID | Primal–Dual | 3.584 | 2.636 | 6.220 |
| ID | EMO，4000 budget | 10.100 | -0.080 | 10.019 |
| OOD | Uniform | 20.276 | 7.349 | 27.625 |
| OOD | Staged | 24.138 | 3.945 | 28.083 |
| OOD | Primal–Dual | 26.325 | 2.587 | 28.912 |
| OOD | EMO，4000 budget | 45.550 | -0.040 | 45.510 |

**结论 A：ID 上的递归收益并不来自更低的第三步 RTF。**

相对 Uniform，Primal–Dual 的 ID 第三步 RTF 高 0.500，但差值小 0.931，最终 recursive 低 0.431。其在真实前缀与预测前缀下的相对表现不同。这个现象与前序预测及模型对前缀变化的响应有关，但现有风险汇总不能区分究竟是前序误差更有利、响应更稳定，还是存在误差抵消。

Staged 的 ID recursive 也低于 Uniform，说明当前收益不只出现在加入约束之后。Primal–Dual 相对 Staged 的 ID recursive 进一步降低约 0.096，幅度较小，尚不能认定为显著的额外收益。

**结论 B：OOD 上，较小的差值不足以抵消较高的 RTF。**

相对 Uniform，Primal–Dual 的 OOD 第三步 RTF 高 6.049，差值小 4.762，最终 recursive 仍高 1.287。其 OOD 最终答案的劣势在提供真实前序答案时已经出现，不能只用递归误差传播解释。

第三步 `Rrec` 的跨种子样本标准差为：

| 方法 | ID 标准差 | OOD 标准差 |
|---|---:|---:|
| Uniform | 0.039 | 0.999 |
| Staged | 0.145 | 1.329 |
| Primal–Dual | 0.258 | 0.886 |
| EMO，4000 budget | 1.124 | 1.636 |

标准差不是置信区间，阴影重叠与否也不是显著性检验。三个种子只能提供有限的优化随机性信息。

### 3.2 中间结果：第二步

| 分布 | 方法 | RTF₂ | Delta₂ | Rrec₂ |
|---|---|---:|---:|---:|
| ID | Uniform | 3.736 | 1.468 | 5.204 |
| ID | Staged | 3.672 | 1.519 | 5.192 |
| ID | Primal–Dual | 3.691 | 1.579 | 5.271 |
| ID | EMO，4000 budget | 3.969 | 1.157 | 5.126 |
| OOD | Uniform | 24.055 | 5.665 | 29.720 |
| OOD | Staged | 24.130 | 4.655 | 28.785 |
| OOD | Primal–Dual | 24.921 | 3.525 | 28.446 |
| OOD | EMO，4000 budget | 28.315 | 1.512 | 29.827 |

**结论 C：Primal–Dual 的 OOD 第二步递归优势，并不等于第二步 RTF 优势。**

相对 Uniform，Primal–Dual 的 OOD 第二步 RTF 高 0.866，但差值小 2.140，因此 recursive 低 1.273。其收益与使用模型预测的前序答案这一条件相关，而不是在两种前缀条件下都取得更低误差。

这个结论具有步骤和分布条件：Primal–Dual 在 ID 第二步的差值反而高于 Uniform，recursive 也略高。不能概括为“Primal–Dual 在所有步骤都降低前缀替换差值”。

EMO 的 ID 第二步 recursive 最低，但 RTF 高于其他方法。这再次说明，recursive 排名并不能直接反推出真实前缀条件下的单步预测能力排名。

## 4. 示例数量变化带来的信息

### 4.1 OOD 的最优方法取决于输出与 n

按均值比较：

- OOD Step 1、Step 2：Primal–Dual 在全部六个 `n` 下均最低。
- OOD Step 3：`n=1` 时 Primal–Dual 最低；`n=2、4` 时 Staged 最低；`n=8、16、32` 时 Uniform 最低。
- ID Step 3：`n=2、4、16、32` 时 Primal–Dual 最低；`n=1、8` 时 Uniform 最低。

这些是当前采样位置的均值排名，不应把“最低位置的数量”当作独立的综合评价指标。如果应用目标是最终答案，应优先比较 Step 3；如果中间答案也必须可靠，应分别报告各步，而不是直接把不同维数、不同尺度的原始误差相加。

### 4.2 更多示例改善 RTF，但递归收益可能被部分抵消

下表为第三步 `n=32` 相对 `n=1` 的均值变化。负数表示该指标下降。

| 分布 | 方法 | RTF₃ 变化 | Delta₃ 变化 | Rrec₃ 变化 |
|---|---|---:|---:|---:|
| ID | Uniform | -2.621 | +1.878 | -0.743 |
| ID | Staged | -2.480 | +1.357 | -1.123 |
| ID | Primal–Dual | -2.245 | +1.014 | -1.231 |
| ID | EMO，4000 budget | +0.077 | -0.056 | +0.021 |
| OOD | Uniform | -8.749 | +2.513 | -6.236 |
| OOD | Staged | -5.329 | -0.055 | -5.384 |
| OOD | Primal–Dual | -4.735 | +0.458 | -4.276 |
| OOD | EMO，4000 budget | -0.120 | +0.462 | +0.342 |

**结论 D：只画 recursive 曲线，会低估某些方法在真实前缀条件下从示例中获得的收益。**

例如 Uniform 的 ID RTF 改善明显，但 recursive 改善较小；两种模式之间的差距随 `n` 增大。OOD 上，Uniform 的第三步 RTF 改善幅度最大，虽然差值也增大，最终在较大 `n` 下仍取得最低 recursive 风险。

这些是端点变化，不代表中间过程单调。当前模型不是随 `n` 继续优化参数；每个 `n` 都是在同一模型、同一批任务和查询上改变 demonstration 前缀长度。

### 4.3 Step 1 的 ID 微升与 OOD 总体微降

| 方法 | ID：n=1 → 32 | OOD：n=1 → 32 |
|---|---:|---:|
| Uniform | 7.305 → 7.372 | 33.172 → 32.801 |
| Staged | 7.312 → 7.369 | 32.970 → 32.209 |
| Primal–Dual | 7.300 → 7.405 | 32.694 → 31.841 |
| EMO，4000 budget | 7.342 → 7.359 | 33.222 → 32.466 |

**结论 E：这不是前序误差累积，RTF 在第一步不会提供另一条独立的风险曲线。**

对三个基线，ID 端点上升约 0.8%–1.4%，OOD 端点下降约 1.1%–2.6%。幅度较小；EMO 的 ID 第一步测试曲线也更接近水平。OOD 并非单调下降，例如 Uniform 从 `n=8` 的 32.481 又升至 `n=32` 的 32.801。

可能解释包括：模型未充分学会利用额外示例识别任务、更多上下文产生干扰、学习到的绝对位置编码引入位置依赖，以及 OOD 示例提供额外的输入尺度与方向信息。增加 `n` 同时改变序列长度和 query 位置，因此现有曲线无法区分这些机制。它们应列为待验证假设，而不是已经证实的原因。

#### 4.3.1 Step 1 ID 上升的轻量前向诊断

为进一步检查原因，只对已保存模型做前向推断，没有训练或 backward。使用原 ID 测试池（256 个任务，test seed=30000）、三个基线和优化种子 11/22/33，CPU 单线程执行约 8 秒。原始结果保存于 [summary.json](../runs/step1_context_diagnostic/summary.json)。CPU 重算与原 CUDA 记录有少量数值差异，以下对照均采用同一 CPU 计算。

首先，三个基线的 9 个“方法×种子”组合，正常输入下的 n=1→32 端点差异均为正。它是当前固定测试池上的一致小幅变化，不代表每个中间 n 都增加，也不能代表跨测试池的普遍规律。EMO 的三个种子端点变化方向不一致。

代码使用可学习的绝对位置嵌入，query 的位置为 `4*n`。诊断保留 n=32 的全部示例、原有顺序、因果掩码和 query 内容，只将 query token 的位置嵌入替换为位置 4 的嵌入；并未将 query 实际移到序列中间。三种子的均值为：

| 方法 | 正常 n=1，query 嵌入位置4 | 正常 n=32，query 嵌入位置128 | n=32，仅 query 嵌入改为位置4 |
|---|---:|---:|---:|
| Uniform | 7.305 | 7.372 | 7.351 |
| Staged | 7.312 | 7.368 | 7.333 |
| Primal–Dual | 7.300 | 7.405 | 7.368 |

位置嵌入干预降低了三个基线的平均 n=32 误差，但没有恢复至正常 n=1 的水平。反向干预也说明位置有影响：保持 Uniform 的 n=1 示例不变，仅把 query 的位置嵌入改成128，均值从7.305升到7.355。以上结果支持位置敏感性是值得关注的因素，同时不能将位置当作唯一原因。干预后的“位置–长度”组合不同于正常协议，且上下文与位置存在交互，不能把这些差值直接相加，或据此精确分摊自然输入下上升的原因。

其次，在 n=32 时保持 query、目标和位置不变，把整个 demonstration 前缀替换为另一测试任务的完整前缀（任务索引循环加一）。Uniform、Staged、Primal–Dual 的均值分别从7.372、7.368、7.405升到7.428、7.423、7.480；9个方法–种子组合的差值均为正。因此，当前模型并非完全不利用正确任务示例；但这不证明它已经充分学会了任务参数推断，也不意味着32个正确示例一定优于1个正确示例。

另一个参照是同一测试池上的无示例条件均值预测器，其风险约7.140。它优于当前模型的这些 Step 1 ID 结果，说明还不能将模型误差接近水平理解成任务本身已经没有改进空间。

较稳妥的解释是：当前模型利用了部分任务相关信息，但增加示例同时改变了位置嵌入与上下文内容/长度，其净效果在这组 Step 1 ID 评估中略为不利。该现象与前序 query 误差传播无关，因为第一步尚无前序预测。若要确认更具体的机制，应另行设计位置控制、示例数量及示例内容的系统对照；这些轻量诊断尚不能替代重新训练后的结构对照或独立测试池验证。

这些曲线支持以下更具体的判断：

- **若“更贴近”指 recursive 与 RTF 的风险差距较小，Primal–Dual 在三个完成分阶段训练的基线中，第三步表现最突出。** ID、OOD 的全部六个 n 上，其平均 Delta 均小于 Uniform 和 Staged。该方向在多数种子配对中也成立：ID 相对 Uniform 为 16/18 个种子–n 组合，相对 Staged 为 17/18；OOD 相对两者均为 17/18。这些组合共享任务和模型，不是 18 次独立重复，不能据此推导显著性。
- **ID 第三步的差距随 n 总体扩大。** Uniform 和 Staged 的均值在所采样 n 上单调增加；Primal–Dual 在 n=1→2 时略降，之后增加。从 n=1 到 32，三方法 Delta 分别增加 1.878、1.357、1.014，而且各自三个种子的端点变化均为正。RTF 改善快于 recursive，说明真实前缀下获得的上下文收益没有完整体现为递归风险的下降；这不等于 recursive 本身变差。
- **OOD 第三步没有统一的单调规律。** 三方法均在 n=16 附近出现较大差距，n=32 又回落；Staged 的两个端点近似相同，不能将其中间变化概括为“基本没有变化”。Primal–Dual 的均值端点略增，但三个种子的方向不一致。
- **结论不能推广到每一步。** Step 1 理论上 Delta=0，本批数据最大绝对差约为 1.2e-6。Step 2 的 ID 差距在三个基线中总体端点上升，且 n=32 时 Primal–Dual 的 1.579 高于 Uniform 的 1.468；OOD 则先升后降，Primal–Dual 的均值在全部 n 上低于另两个基线。
- **EMO 的近零均值还包含种子间抵消。** OOD 第三步 n=32 的三个种子 Delta 约为 -0.121、-0.596、+0.596，平均约 -0.040，而绝对值的平均为 0.438。其两种风险本身也很高。因此，近零均值不能解释成各模型均对前序答案扰动不敏感。

“风险差距较小”与“预测输出更接近”仍是不同命题。Delta 是两种预测相对目标的平方误差之差，不是两种预测之间的距离。若要直接判断前缀响应敏感性，应另测同一任务上的 `||prediction_rec - prediction_TF||²`，并结合真实前缀预测误差的交叉项解释；若要区分上游误差大小与下游响应差异，则仍需使用统一的受控前序扰动。目前不需要重新训练即可计算本文的 Delta 曲线。

### 4.5 为什么 ID 与 OOD 的 Delta 形状不同

先区分数据分解与机制解释。对两个示例数量，恒有：

`Delta(n_b)-Delta(n_a) = [Rrec(n_b)-Rrec(n_a)] - [RTF(n_b)-RTF(n_a)]`。

因此，差距先扩大再缩小，直接对应的是两种推断模式改善速度的相对变化，而不是已经证明“误差传播先增强后减弱”。以 Primal–Dual 三种子均值为例：

| 分布与步骤 | n 的区间 | RTF 变化 | Rrec 变化 | Delta 变化 |
|---|---|---:|---:|---:|
| ID Step 3 | 1→32 | -2.245 | -1.231 | +1.014 |
| OOD Step 2 | 1→2 | -3.175 | -1.385 | +1.789 |
| OOD Step 2 | 2→32 | -1.837 | -3.932 | -2.095 |
| OOD Step 3 | 16→32 | +0.255 | -1.649 | -1.904 |

ID 第三步的扩大来自 RTF 改善更多，而不是 Rrec 必然恶化。OOD 第二步的前段同样是 RTF 改善更快；后段则是 Rrec 改善更快，因而缩小差距。这与“少量示例先有利于真实前缀下的预测，较多示例后递归预测获得更多额外收益”的描述一致。

OOD 第三步的末段还存在不同的成分：三个基线的 RTF 均值均略微变差，与 Rrec 的改善共同缩小差距。

| 方法，OOD Step 3，n=16→32 | RTF 变化 | Rrec 变化 | Delta 变化 |
|---|---:|---:|---:|
| Uniform | +0.252 | -1.723 | -1.975 |
| Staged | +0.362 | -1.851 | -2.214 |
| Primal–Dual | +0.255 | -1.649 | -1.904 |

机制上，一种合理但尚未识别的解释是：新增上下文对真实前缀条件下预测的帮助先显现，而递归预测还受上游答案偏差制约；更多示例之后，任务信息、输入尺度信息或上游预测改善，使递归结果追赶。ID 的新增示例则没有给第一步带来相同方向的风险改善。这些事实方向相符，但仅靠风险均值不足以证明该机制：下游对前缀的敏感性、误差方向和误差抵消也可能变化。

还需限制对“曲线形状”的概括。ID 第二步也在 n≈8 后有回落；OOD 第三步的末段下降主要是16→32这一个采样区间，不能外推为更大 n 下持续下降。Primal–Dual 的 OOD 第三步 Delta 在该区间的三个种子变化约为 +0.416、-0.539、-5.588，均值回落主要由 seed33 贡献；相比之下，其 OOD 第二步该区间的三个种子 Delta 均下降。

下一步若只增加诊断，应将 Delta 拆成 `E||prediction_rec-prediction_TF||²` 与交叉项 `2E< prediction_rec-prediction_TF, prediction_TF-target >`，并联合观察上游预测误差。前者下降支持两种模式的输出更接近；主要由交叉项变得更负驱动的下降，则可能反映误差抵消，不能称为前缀响应更稳定。本节仅分析已保存评估数据，没有新增训练。

## 5. EMO 的特殊限制

三个训练记录均为 `budget_exhausted:level2`。截至 4000 次 backward，尚未进入包含 `f3` 的最终层优化；不能将其视作完成全部求解后的模型。

三个种子的训练 `e3` 约为 1.04–1.15，而测试第三步 RTF 也很高。结合第三步 RTF 对 `n` 基本没有改善的现象，更有依据的解释是：当前预算内，模型尚未完成面向最终目标的训练。共享参数更新仍会影响第三步输出，但不等于已经针对最终层目标完成训练。

第三步 `Delta` 接近零、甚至为负，并不能说明 EMO 最能抵抗误差传播。其最终输出可能尚未有效利用真实或预测的 query 中间答案，也可能存在误差抵消；仅凭汇总风险不能确认。需要进行前序答案替换、打乱或受控扰动实验。

图例应标明“EMO，4000 backward，停止于 level 2”。允许报告它在该预算内的实际表现，但不能据此断言完整 EMO 方法本身泛化较差。更高预算的完整运行应单独分析，不能直接与当前三种子、4000 次预算结果作同等计算成本比较。

## 6. 为什么 Uniform 没有显式约束，也能保持前层表现

本节分析全训练集上的归一化损失，与前文测试集上的原始风险区分。训练曲线每 250 次 backward 评估一次，下面关于中间过程的判断仅覆盖这些记录点，不能保证两次评估之间的每一次 minibatch 更新都可行。

### 6.1 Uniform 始终在直接优化前两步

当前目标定义为

`f1 = e1`，`f2 = (e1 + e2)/2`，`f3 = (e1 + e2 + e3)/3`。

Uniform 始终优化 `f3`，其梯度包含

`∇f3 = (∇e1 + ∇e2 + ∇e3)/3`。

因此，前两步从未退出训练目标，始终受到直接的优化压力。这与“先训练前层，后续只优化 e3”不同：后一种设置更直接地暴露后层训练可能破坏前层的问题。Uniform 保持较好的 `f1、f2`，不必完全用任务之间存在强正向协同来解释；目标中持续包含前层损失，本身就能提供部分解释。

这并不保证前层损失单调下降。如果其他步骤的更新方向与前层冲突足够强，优化累计平均损失仍可能牺牲前层。实际 Adam 更新还受动量与自适应缩放影响，仅凭目标中包含某项损失不能给出逐步可行性保证。

### 6.2 当前公共阈值对 Uniform 的实际限制较弱

4000 次更新后的三种子平均训练指标为：

| 方法 | f1 | f2 | f3 |
|---|---:|---:|---:|
| Uniform | 0.6970 | 0.5622 | 0.4683 |
| Staged | 0.6965 | 0.5667 | 0.5058 |
| Primal–Dual | 0.6944 | 0.5724 | 0.5258 |

这些训练终点在本次结果中也对应 `selected` 模型。配对阈值的三种子均值约为 `b1 = 0.7180`、`b2 = 0.6103`。阈值均值只用于展示尺度；是否可行必须用各个种子自己的配对阈值检查，不能仅比较两个均值。

逐种子核验结果是：Uniform 从第 1500 次更新起，在全部已记录的评估点上均满足两条公共训练约束。其最终平均残差为

`f1 - b1 = -0.02096`，`f2 - b2 = -0.04812`。

也就是说，Uniform 最后不仅可行，而且有明显余量。Primal–Dual 得到略低的 `f1`，同时得到较高的 `f2、f3`。相对于当前设定的阈值，额外的前层保护没有显示出维持最终训练可行性的必要性。

这不是对无约束全局最优解可行性的证明，而是对当前有限训练轨迹和终点的观察。全训练集有余量也不意味着所有 minibatch 都满足约束；根据 minibatch 更新的乘子仍可能为正，并继续影响训练方向。

### 6.3 存在暂时的目标冲突，但没有超过当前容忍范围

Staged 从第二阶段进入第三阶段后，平均 `f2` 从第 2500 次更新时的 0.5785 回升到第 2750 次时的 0.5984。同期平均 `e3` 从 1.1610 降至 0.6277。

因此，训练更充分地纳入第三步目标时，前层累计指标确实可能暂时变差。只是三个种子的这次回升仍未突破公共阈值，随后 `f2` 又下降至最终的 0.5667。不能从最终可行性推出目标完全没有冲突，也不能因为出现短暂回升就认定显式约束必不可少。

更合适的表述是：**在当前模型、任务、预算与容忍度下，已观察到的目标冲突相对温和；持续优化前层损失和公共阈值提供的余量，使无约束方法也能保持可行。**

### 6.4 目标重叠与梯度协同是两件事

- **定义上的重叠已知存在。** `f3` 包含 `e1、e2`，`f2` 也包含 `e1`，它们不是互不相关的三个独立目标。
- **参数上的耦合已知存在。** 三步预测共享模型参数，一步的更新可能改变其他步骤。
- **梯度是否正向协同尚未测量。** 共享参数和损失重叠，不代表各步梯度始终同向。损失曲线同时较低，也不能代替梯度夹角或方向导数测量。

若要解释“为何正常优化 f3 足以保护前层”，可在相同参数点测量各 `∇ei` 的范数和余弦相似度。对实际 Adam 更新，还应考察 `∇fi` 与真实参数增量的内积，并核对更新前后的全池损失变化。这样才能区分直接的前层优化压力、任务梯度协同和有限步优化中的其他影响。

### 6.5 分阶段方案的价值与显式约束的价值应分别判断

| 问题 | 当前证据支持的判断 |
|---|---|
| 是否需要分阶段才能维持前层训练可行性？ | 没有显示必要性，Uniform 已能满足公共约束。 |
| 分阶段方案是否可能改变优化路径和泛化？ | 可能，部分 ID 最终递归结果更好；但这不是前层保护机制的直接证明。 |
| 显式约束是否带来额外收益？ | 应重点比较 Staged 与 Primal–Dual；当前收益依步骤和分布而变，尚无全面优势。 |
| Uniform 与 Staged 的差异能否只归因于目标顺序？ | 不能，当前方案还同时改变了优化器状态重置方式。 |

研究笔记第 24 页规定最终优化 `f3` 并检查两条累计目标约束。实际 minibatch Primal–Dual 实现不构成每一步都满足硬约束的保证；理论中的近似可行性与最优性结论有其假设，不能直接解释为非凸 Transformer 训练损失单调不升，也不自动保证递归测试风险改善。

可用于报告的表述为：

> 当前实验尚未呈现显式优先级约束对于保护前层训练目标的必要性。Uniform 的累计目标持续包含早期步骤损失，并在后续已记录的训练点中满足公共阈值。分阶段方案在部分 ID 递归预测上的收益，尚不能归因于避免了无约束基线的前层约束违规。目标定义上的重叠是已知事实，梯度协同程度和约束带来的独立作用仍需进一步对照实验识别。

### 6.6 局部目标消融、统一新目标与应展示的训练图

仅在同一第二阶段 checkpoint 后比较 `f3`、`e3`、`e3+前层约束`，是第三阶段的局部机制消融，能检查“累计目标的直接保护”和“显式约束的保护”。它不能替代三层目标统一重定义后的完整主实验，也不能将其结果直接称为原研究笔记协议下某个算法的全面优势。

若希望建立另一套完整实验，应先明确新的目标 `g1/g2/g3`，然后在各方法中一致使用。最小的定义对照是 `g1=e1、g2=e2、g3=e3`：Staged 依次优化 g1/g2/g3；Primal–Dual 的参考值、约束及更新均对应 g。联合训练基线可明确定义为三个 g 的等权平均。第二阶段应按新的 g2 训练，不能将旧 f2 得到的阶段末状态直接当作新体系的标准阶段末状态；阈值也应依新目标重新计算。这属于补充目标定义实验，需与原累计 f 协议分开报告。

该单步体系现已实现为 `--objective-family per_step`，默认仅 seed11、Uniform/Staged/Primal–Dual，排除 EMO；输出目录为 `runs/per_step_objectives`。该目录中 `f1/f2/f3` 就表示 `e1/e2/e3`，checkpoint、测试结果及分析表均记录目标体系。原累计目标仍是默认选项，新旧体系不能混入同一实验目录。保留 PD 的逐步 dual 记录，f 图按当前定义显示目标和阈值。已完成小规模正确性检查及每方法15次更新的端到端检查，没有在本机启动4000步正式实验，微型结果不能用于判断约束收益。GPU运行命令与具体选择规则见 [experiments/README.md](README.md)。

移除代数重叠不保证任务梯度冲突。单步 e1/e2/e3 仍来自同一推理任务，也可能共享有用表示。目标数值的低相关度更不等于需要约束：若各目标使用独立参数，就可能互不干扰。要检验保护机制，应检查共享参数更新是否损害前序目标，以及损害是否超出预先定义的容忍范围。若单步目标下仍没有退化，再考虑具有明确资源取舍的任务或共享表示瓶颈；不能仅凭当前结果判断换更大模型会使约束更有价值。

## 7. 能支持什么，不能支持什么

### 7.1 可以支持的研究表述

> 在当前固定训练池、配对初始化和训练预算下，分阶段训练在多个 ID 设置中获得了较低的最终递归误差。引入 Primal–Dual 约束后的收益具有步骤与分布依赖性：其 OOD 前两步递归风险较低，但未一致延伸至最终答案。联合 teacher-forced 评估发现，方法在真实与预测前缀条件下的风险排名可以反转，因而单独的 teacher-forced 风险、递归风险或二者差值都不足以完整评价模型。有限预算 EMO 的最终一步劣势同时出现在两种前缀条件下，并伴随未进入最终层优化的训练状态，不能主要归因于递归误差传播。

### 7.2 不应写成的结论

- “Primal–Dual 全面优于其他方法”或“在所有步骤上抑制了误差传播”。
- “Delta 更小，所以递归鲁棒性一定更强”。
- “前两步平均平方误差更小，所以最终答案必然更准”。
- “EMO 第三步差，说明完整 EMO 算法无效”。
- “增加示例一定有利”或“Step 1 上升证明模型完全没有利用示例”。
- “OOD 原始误差比 ID 大，所以差额全部是泛化损失”。OOD 输入协方差和目标尺度均发生变化，宜补充目标能量归一化或简单基线对照。
- “只有显式约束才能维持前层”。三个基线的最终模型均满足配对公共训练阈值，当前结果没有展示约束对于最终训练可行性的必要性。
- “Uniform 能保持前层，所以三个目标的梯度一定高度一致”。目标重叠可以直接从定义确认，梯度协同则需要额外测量。
- “分阶段的测试收益证明显式约束有效”。目标顺序、优化器重置与约束作用需分别识别。

此外，训练集可行性不是测试集可行性保证。配对优化种子只反映固定数据上的部分训练随机性，不覆盖训练池或测试任务采样的变化。本分析未实施显著性检验，也未将全部 `n` 任意平均为一个综合分数。

## 8. 后续最有价值的分析与实验

### 8.1 已有数据即可补充

1. 按步骤与分布同时画 `Rrec(n)`、`RTF(n)`、`Delta(n)`，差值图保留零线。Step 1 可只展示一条风险曲线并注明两种模式相同。
2. 报告每个优化种子的配对方法差异，避免仅依据均值排序；现有 `selected` 与 `last` 在这批结果中一致，无需重复展示相同曲线。
3. 在最终比较表中同时给出风险、训练可行性与实际计算成本。较小的风险差值不能替代这些指标。

### 8.2 需要新增实验，才能判定机制

1. **区分前序误差与响应敏感性。** 在同一模型、同一批任务上，分别使用真实、模型生成及受控扰动的前序答案。对第三步分别替换第一、第二个中间答案，避免只做同时替换而混淆作用。
2. **识别显式约束的独立作用。** 从同一第二阶段 checkpoint 分叉，一支只优化 `f3`，另一支优化 `f3` 并加入 Primal–Dual 约束。两支使用相同 minibatch 顺序、Adam 初始状态和第三阶段预算，同时跟踪训练约束、RTF 和 recursive 风险。进一步测量单步损失的梯度夹角，以及累计目标梯度与实际更新方向的关系；若研究不同容忍度，应按各自协议重新校准参考值。不能仅凭当前排名认定约束导致了某项结果。
3. **区分上下文信息与位置效应。** 固定或显式控制 query 位置，比较增加正确示例、增加无关示例和打乱任务对应关系的结果。当前模型的绝对位置编码使这一对照尤为重要。
4. **扩展统计与预算范围。** 增加独立数据池和测试任务，并通过验证集调整超参数；将 EMO 的预算扫描与完成运行分开展示。汇总均值不足以完成这些验证。

### 8.3 动态反馈需要逐步记录，不能只依赖每 250 步的采样点

**采集结论：为观察 dual 的动态反馈，应保存每一次 dual 更新，而不是每 250 步只取一个瞬时值。** 现已在 Primal–Dual 训练中实现逐步采集，其他方法不增加此记录；旧实验的稀疏记录仍无法恢复这些逐步量。

实现保存每个种子 3000 条有效 dual 更新记录（不补 Stage 1 的空行）。新 checkpoint 的 `dual_history` 经 `experiment_analysis` 导出为 `tables/dual_history.csv`，并生成每种子独立的 `figures/dual_feedback_seed*.png`。最终阶段超过 100 步时，另取该阶段 `|delta_lambda|` 最大位置附近的 100 步生成局部图，窗口在阶段边界处截取并补足；这是用于检查响应的诊断窗口，不代表全程统计。四行面板分别展示 `c_hat`、`q`、`delta_lambda`、`lambda_after`，保留所有原始点，分开阶段并标记乘子重置。全池评估以独立标记叠加，区分 Adam 后评估与阶段恢复快照。`tables/dual_feedback_coverage.csv` 标出旧 checkpoint 缺失记录的情况。以下固定 probe 属于进一步建议，本次未增加 probe 评估。

按当前 `1000 + 1500 + 1500` 的配置，每个优化种子的数据量为：

| 阶段 | 累计模型更新编号 | Dual 状态 | 逐步记录数 |
|---|---|---|---:|
| Stage 1 | 1–1000 | 尚未启用 | 若保留完整训练轴则记录 1000 行，dual 字段留空 |
| Stage 2 | 1001–2500 | 每步更新 lambda1 | 1500 |
| Stage 3 | 2501–4000 | 每步更新 lambda1、lambda2 | 1500 |

因此，每个种子实际有 **3000 条 dual 更新记录**；若统一保存完整训练轴，则为 **4000 行**。Stage 3 的两个乘子保存在同一行，不需要拆成两倍行数。Stage 1 的未启用状态应与“已启用但乘子恰好为零”区分。

每次更新至少保存累计编号、阶段、阶段内编号，以及每条已启用约束的以下量：

| 字段 | 含义 |
|---|---|
| `c_hat` | 当前 minibatch 的更新前残差 `f_hat_i - b_i` |
| `lambda_before` | 本次 dual 更新前的乘子 |
| `q` | 真正驱动 dual 的信号 `c_hat - nu * lambda_before` |
| `lambda_after` | 本次 dual 更新后的乘子 |
| `delta_lambda` | `lambda_after - lambda_before` |
| `b_i、nu、omega` | 残差与更新公式所用的阈值、正则化和阻尼参数 |

对应更新关系为

`lambda_after = max(0, lambda_before + (omega/nu) * q)`。

在当前参数下，即 `lambda_after = max(0, 0.95 * lambda_before + 2.5 * c_hat)`。乘子的增加由 `q > 0` 决定，而不是仅由 `c_hat > 0` 决定。上述残差及乘子数据均可复用训练中已计算的量，不要求额外的模型 forward 或 backward；保存标量仍有少量记录与设备同步开销。

建议使用三种互补的记录频率：

- **每一步：**保存 minibatch 残差、驱动信号和乘子前后值，检查更新响应。
- **每 5–10 步：**在固定的约 256 个训练样本组成的 probe 集上评估约束，观察同一批样本上的模型变化。probe 残差是近似量，不能标为精确全训练集约束。
- **每 250 步：**保留全训练集评估，校验经验可行性及 probe 的代表性。

额外 probe 评估会增加 forward 与运行时间，应单独统计，不能因为没有增加 backward 就视作没有计算成本。逐步 minibatch 日志本身不能替代固定 probe 或全池评估，因为相邻 batch 的变化混合了模型变化与样本差异。

记录必须注明参数时点：`c_hat、lambda_before、lambda_after` 在该次模型参数更新前采集，`lambda_after` 用于随后的 primal 更新；原有全池指标通常在模型更新后测量。若展示前后反馈，需要明确两者对应的模型状态，不能把不同状态的值无标注地当作同点数据。

绘图应保留每个种子的逐步原始点，可叠加短窗口均值，但不应只展示平滑后的曲线或仅保留跨种子均值。先用全程图定位，再放大局部窗口，联合展示约束信号、`q` 与 `delta_lambda`、乘子和后续固定 probe 残差。在第 2500 次更新完成、进入 Stage 3 时显式标出乘子重置，避免跨阶段连线被误读为自然反馈。

这些记录能检查“残差如何驱动乘子，以及之后约束如何变化”。若要进一步证明约束改善来自 dual，而不是普通训练本身，仍需第 8.2 节的同起点、同数据顺序、同预算分叉对照。
